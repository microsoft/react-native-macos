# react-native-macos agent knowledge

Start here when [AGENTS.md](../../AGENTS.md) doesn't answer your question. Open only the topics whose "Load when" matches your task, plus the topics they list under `requires`.

To add, change, move, or retire knowledge, use the [`rnmacos-organize-knowledge`](../skills/rnmacos-organize-knowledge/SKILL.md) skill. To search every knowledge home, run `node .agents/knowledge/tools/knowledge.mts find <terms>`.

Vocabulary, budgets, and routes are in [taxonomy.yaml](taxonomy.yaml). The tables below are generated by `knowledge.mts index --write`; don't edit them by hand.
